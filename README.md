# Light Guide

A guide and browser installer for the Light Phone III. Unlock the bootloader, install LightOS or LineageOS with ReSukiSU and microG, or restore stock firmware.

> [!CAUTION]
> Unlocking and switching operating systems erase your data. Back up before starting.
>
> Supports the Light Phone III (`TLP301`) running firmware `00WW_1_440000`. LineageOS support is experimental.
